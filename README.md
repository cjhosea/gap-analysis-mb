# Gap Analysis

## Overview

CISA's Cyber Security Evaluation Tool (CSET) is a tool designed to help organizations systematically evaluate their security posture and perform a gap analysis. Using CSET, organizations can assess their ICS networks and systems based on NIST SP 800-82 revision 3. 

NIST SP 800-82 is a document that provides guidance on how to secure operational technology assets and the systems and networks surrounding them. 

This gap analysis is an extension to my previous project (https://github.com/cjhosea/modbus-detection-lab).
